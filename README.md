# Ads Mastery Line

A personal Google Ads + Meta/Instagram ads curriculum rendered as a transit
map: 101 one-hour stations across 9 lines, zero to paid-ads operator. Same
engine as the LLM Mastery, Marketing Mastery and Business AI Conduit lines;
this one rides on espresso with a mustard-leather accent.

- **Now boarding** — the next station for tonight, with links.
- **Network map** — the whole journey as a snaking metro line; the pulsing
  ring is where you are.
- **Departures** — the self-adjusting schedule. Skip a day and every future
  station shifts forward automatically.
- **All stations** — every station with a checkbox and a private log entry.

Free first: official docs, Skillshop, Meta Blueprint and the practitioners
worth watching. The only paid station (optional Meta certification) is
flagged. Progress lives in this browser via localStorage
(`ads_mastery_v1`); export a JSON backup from **Service**.

Short term (stations 1–60): foundations, Google Search, Google beyond
search, Meta tracking, Meta campaigns — campaigns live on a real SMB.
Long term (61–101): creative studio, audiences, measurement, scale & pro
operations — the terminus is a 30-day live campaign run end to end.
